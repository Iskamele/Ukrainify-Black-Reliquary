# Black Reliquary — українська локалізація

Неофіційний переклад українською. У роботі: готової збірки поки немає.

## Стан

| Етап | Стан |
|---|---|
| Рушій і шрифти: українські літери в грі | перевірено в меню |
| Глосарій і гайд зі стилю | чернетка, на вичитці |
| Пілот: 186 рядків | на вичитці |
| Основний переклад | не почато, чекає на глосарій |

Перед основним перекладом глосарій варто звірити з офіційною українською локалізацією Darkest Dungeon II.

Репозиторій містить лише інструменти. Текст гри, переклад і глосарій сюди не входять.

| Шлях | Що це |
|---|---|
| `translation/` (не в репозиторії) | переклад і глосарій; зберігаються окремо |
| `tools/extract.py` | витягає англійський текст гри в `local/` |
| `tools/check.py` | перевіряє переклад |
| `tools/merge.py` | вливає порцію перекладу |
| `tools/proof.py`, `tools/proof.html` | вичитка глосарія й перекладу: таблиця `translation/proofreading.csv`, `--web` показує її в браузері |
| `tools/build.py` | збирає мовні файли, встановлює (`--install`) і видаляє (`--uninstall`) їх; `--proofread` бере лише вичитані рядки |
| `tools/br.py` | спільна бібліотека |

Список мов вкомпільовано у гру, тому переклад займає слот французької. Гра має бути придбана.

## Вичитка

```
py tools/proof.py --web      вичитка в браузері: → прийняти, ← відхилити, ↓ коментар
py tools/proof.py --status   поступ за розділами
py tools/proof.py            синхронізувати правки з таблиці
```

Текст правиться в таблиці `translation/proofreading.csv` (Excel, зберігати як CSV UTF-8). Вичитаний рядок глосарія стає затвердженим.
